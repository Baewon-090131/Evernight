# Evernight

一个自制自用的相册整理工具。当前版本为 `v0.2 Get Up`，目标是先完成一套可以在真机相册上实际使用的核心流程。

## v0.2 已实现

- 通过 PhotoKit 请求相册读写权限。
- 按拍摄月份读取照片和视频。
- 在滑动整理页切换 `全部媒体 / 照片 / 视频`。
- 整理卡按媒体原始比例自适应尺寸，并使用高分辨率 PhotoKit 请求与分尺寸缓存。
- 左滑下一张、右滑撤回、上滑加入待删除、下滑放入目标相簿。
- 下一张卡使用透明度与缩放交叉过渡，右滑撤回会反向播放上一步动作。
- 下滑时显示横向相簿投放栏，支持连续浏览相簿并将卡片缩放到目标格。
- 创建用户相簿并设置默认归档相簿。
- 扫描整个相册中的相似照片，推荐保留分辨率与拍摄时间综合更优的一张。
- 智能整理默认扫描一次整个相册，不再逐月确认。
- 在相似组内逐张选择，并批量加入待删除区。
- 重命名、删除相簿，并合并名称相似的重复相簿。
- 保存每月整理进度和本地累计统计。
- 保留最近 50 次相簿移动记录，并支持逐条撤销。
- 待删除区二次复核。
- 使用滑轨确认删除，未到终点自动回弹，满轨后交给 iOS 系统再次确认。
- 待删除与更多相簿抽屉使用屏幕高度的 4/5，便于确认列表与选择目标相簿。
- 视频可直接播放，实况照片支持按住播放，并在滑走、离开页面或进入后台时暂停。
- 视频与实况照片的自动播放可在设置中分别开关。
- iOS 26 上使用 Liquid Glass；较低系统版本使用系统材质回退。
- 全部应用文本统一使用苹方，并支持动态字体。

当前相似识别只扫描有拍摄日期的照片，视频和未标注日期的媒体暂不参与。

## 技术栈

- Swift 6 语言模式
- SwiftUI
- PhotoKit
- 苹方字体与动态字体
- iOS 18 最低部署版本
- iOS 26 SDK 与 Liquid Glass 原生 API
- XcodeGen 生成 Xcode 工程

## 本地构建

需要 macOS、Xcode 26 和 XcodeGen。

```bash
brew install xcodegen
xcodegen generate
open Evernight.xcodeproj
```

也可以直接构建产物：

```bash
bash scripts/build-ipa.sh
```

未签名 IPA 输出到 `artifacts/Evernight-v0.2-Get-Up-unsigned.ipa`。

## GitHub Actions 构建 IPA

仓库只保留 `Build unsigned IPA` 工作流：

- 手动运行、推送 `main` 分支或推送 `v*` 标签时触发。
- 生成未签名 IPA。
- 适合通过 AltStore、Sideloadly 或其他自签名工具安装。
- 未签名 IPA 不能直接在未经处理的真机上安装。

## 测试

`EvernightTests` 使用 Swift Testing 覆盖滑卡状态和撤回逻辑。CI 会执行 `build-for-testing`，确认 App 与测试目标能够编译。

## 权限与数据

- 照片读取、缩略图回调和整理索引均在本机完成。
- v0.2 不上传相册内容。
- 待删除项目只保存在内存中。
- 点击删除后仍会经过 iOS 系统删除确认，并可在系统“最近删除”中恢复。
- 应用进入后台时会用长夜月图案遮住相册内容。
